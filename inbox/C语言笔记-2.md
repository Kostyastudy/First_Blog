## 常量
在程序运行过程中，其值不可以改变。可以简单理解成数学中的常数
使用const修饰的变量
```c
#include <stdio.h>
int main(int argc, char const *argv[])
{
	const int a = 10;
	a = 5;
	return 0;
}
```
会报错 error: assignment of read-only variable 'a'
## 标识符
标识符的命名规则如下:
C语言中用来给变量、常量、函数等内容起名字时用的字符序列
标识符由字母、数字、下划线_组成，且必须以字母下划线开头不能使用C语言的关键字作为标识符

![[Pasted image 20261023174119.png|444]]

1 Byte = 8 bit
有符号数 -2^31 ~ 2^31 -1
```c
#include <stdio.h>
int main(int argc, char const *argv[])
{
	int a10 = 156, b = -5, a16 = 0x156, a8 = 0156;
	printf("十进制：a10 = %d \n",a10);//156
	printf("八进制：a10 = %o \n",a10);//234
	printf("十进制：a8 = %d \n",a8);//110
	printf("十进制：a16 = %d \n",a16);//342
	printf("十六进制：a10 = %x \n",a10);//9c
	printf("十六进制：a10 = %X \n",a10);//9C
	printf("十六进制：a16 = %X \n",a16);//156
	printf("无符号：a10 = %u \n",a10);//156
	printf("无符号：b = %u \n",b);//4294967291
	return 0;
}
```
