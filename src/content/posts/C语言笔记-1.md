## 什么是编程？
根据需求设计出来的一套标准化的流程。
eg.每个人通过一样的微信，网站点击，标准化流程完成指定需求，任务；肯德基，预制菜。
写代码只是一种实现的方式。

编程难吗？
编程怎么学？
知识（定理定律， 文常。这些要背的）的学习与能力的获取（操作实践。这需要习得）是两条路
eg.光看书能学会游泳吗？

学习的过程？
eg.学写字先模仿，组词积累，写句子、文章
1.模仿，2.重复，3.独立思考（思路，思想）。

怎么顺利通过考试，拿高分？
真正掌握代码能力

建议：
标准指法练习打字！
课件讲过的代码独立练习5-10遍（眼睛看的懂不代表手敲得出来）。

## 计算机语言发展史

1.01打孔机
2.汇编语言
3.高级语言

C语言：Dennis Ritchie设计UNIX操作系统，由Basic语言构想出来。
《The C Programming Language》
C89标准，C99，C11
特点：高效（执行效率而非开发效率），可移植性（Windows，Linux等系统上都能运行），功能强大灵活，面向开发人员

应用：嵌入式，数据库，分布式，游戏开发/游戏引擎，编程语言，操作系统，桌面程序开发，虚拟化技术

学什么：数据类型、运算符和表达式、程序流程控制结构、数组和字符串、函数、指针、内存管理、复合类型、文件操作

## 1.开发环境的安装与搭建
开发工具：写代码
Visual Studio（IDE，集成开发工具），Sublime（轻量一点）
开发环境：运行代码（编译（翻译成机器懂的语言），运行）

```c
#include <stdio.h> //standard input output 里面有printf等函数
int main(int argc, char const *argv[])
{
	printf("hello world\n");
	printf("hello kitty\n\n");
	return 0;
}
```

代码解析：
	C语言的源文件扩展名为.c
	引入头文件
	main函数的写法是固定的
	printf()用来实现输出
	程序总是从main函数开始执行
	将字符串放入printf()中会原样输出
	\n表示换行
	语句总是以分号结束;
