# 卓才 · 新生启航计划（12 讲）

> 由 12 份课程转录稿校对整理：删除语气词、口头禅、重复与闲聊，修正语音识别错字，保留全部知识点、案例、数字与作业要求。每篇结构统一为「摘要 / 核心要点 / 课后任务 / 讲稿（带发言人标注）/ 校对存疑」。

## 一、AI 入门

- [[1.1 大模型入门]]：大模型为什么会一本正经地胡说、四个概念的分层、选模型的四问，以及提示词、追问与核验的基本功。
- [[2.3 提示词工程]]：上下文窗口与滑动窗口的机制，六个提示词技巧，以及从需求澄清到代码生成的完整迭代流程。
- [[3.3 智能体与技能]]：从 ReAct 到 MCP 的 Skill 演进史，Skill 怎么写、怎么复用、怎么被 Agent 按需调用。
- [[4.2 Claw 与 WorkBuddy]]：Pi → OpenClaw → WorkBuddy 的技术脉络，Agent 的组件、沙箱与实战搭建。
- [[4.3 作品讲解及答疑]]：两批作业逐份讲评、评分细则、AI 生成代码的常见缺陷，以及上线与部署答疑。

## 二、大学认知与学习

- [[1.2 大学认知]]：大学和高中是两套游戏——环境、规则、角色三层变化，以及怎么读《培养方案》、怎么算绩点。
- [[1.3 大学学习方法]]：目标—方法—思辨三个层次，课程结构、知识体系、批判性思维与 AI 时代的稀缺能力。
- [[3.1 时间与任务管理]]：从个人日历到团队项目，三层时间排布、20% 机动、WBS 拆解与甘特图。
- [[4.1 大学四年总体规划]]：目标—路径—任务—证据—复盘的执行链，五大发展路径，成绩作为基本盘。

## 三、通用能力

- [[2.1 简历]]：六大模块与 STAR 法则，针对学生组织、科研导师、竞赛、实习四类场景的差异化写法。
- [[2.2 沟通协作]]：说服即自我说服、反抗机制、说教者与点燃者的语言策略、135 表达法则。
- [[3.2 策划案与表达]]：对象—目标—方案—证据—行动的选择链，策划案怎么写、怎么讲、怎么控风险。
