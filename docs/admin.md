# 写作台（本地管理后台）

不想面对文件夹和终端时，用这个本地网页改内容。

## 启动

在 `C:\blog` 打开 PowerShell：

```powershell
npm run admin
```

会自动打开 **http://127.0.0.1:4322**。关闭：在终端按 `Ctrl + C`。

> 写作台只监听本机，不要把它暴露到公网。

## 能做什么

### 文章

- 列出全部文章，支持搜索；
- 点标题进入编辑：标题、摘要、分类、日期、标签、Markdown 正文；
- 「预览」可以直接看排版和公式（KaTeX）；
- 新建文章、删除文章；
- 保存只改本地文件，点右上角「发布上线」才会更新线上。

### 资料

- 把 PDF / Word / PPT / ZIP / Markdown 拖进虚线框，或点击选择；
- 单个文件上限 **50MB**，超过会直接提示并跳过；
- PDF 和 Word 会自动生成资料库条目；
- Markdown 会先放进 `inbox/`，需要到「操作与日志」点「导入 inbox」；
- 列表里可以预览或删除资料。

### 站点设置

改站名、英文名、浏览器标题、简介、首页两行大标题、页脚文案、作者、邮箱、开始年份。

保存后仍需「发布上线」。

### 操作与日志

- **导入 inbox**：运行 `npm run import`；
- **只构建检查**：运行 `npm run build`，不发布；
- **构建并发布**：构建 → `git add` → `git commit` → `git push`；
- 日志会实时滚动，失败时看最后几行。

## 发布流程

1. 改文章 / 传资料 / 改设置；
2. 点右上角 **发布上线**；
3. 等日志出现「已推送」，约 1–2 分钟后刷新线上站点。

推送需要 Clash 开着，否则会卡在 `git push`。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 打不开 4322 | 确认 `npm run admin` 还在运行；端口被占用时换端口：`$env:ADMIN_PORT=4400; npm run admin` |
| 上传 50MB 以上失败 | 设计如此，先把文件压小或改用网盘 |
| 发布失败 | 看日志；构建失败先修内容，git 失败检查 Clash |
| 改了没生效 | 需要点「发布上线」，保存本身不上线 |
| 想撤回 | 用 `git log` 找上一个提交，`git revert` 或让 AI 处理 |

## 边界

写作台只管理**内容**（文章、资料、站点文字）。布局、配色、动画这些仍然建议通过对话让 AI 改，避免在网页里编辑代码。
