# 写作台（本地管理后台）

不想面对文件夹和终端时，用这个本地网页改内容。

## 启动

在 `C:\blog` 打开 PowerShell：

```powershell
npm run admin
```

会自动打开 **http://127.0.0.1:4322**，同时自动启动本地预览 **http://localhost:4321**。

关闭：在终端按 `Ctrl + C`，两个服务会一起停。

> 写作台只监听本机，不要暴露到公网。

## 资料库

笔记和文件现在放在同一个「资料库」里，按文件夹归类：

```text
微积分Ⅰ / 线性代数 / 保研资料 / 学习方法 / 其他
```

- 左边是文件夹树，支持多级子文件夹；
- 点文件夹筛选；「全部」显示所有条目；
- 选中某个文件夹后，点「+ 新建文件夹」会在它下面建子文件夹；
- 条目可以直接拖到左侧文件夹里，只改归类，**不改变已有 URL**；
- 文件夹里还有内容或子文件夹时不能删除；
- 「新建笔记」会在当前文件夹里建一篇 Markdown 笔记；
- 「上传文件」前先选「上传为 资料 / 笔记」，再拖入或选择 PDF / Word / PPT / ZIP；
- 类型由你上传时的选择决定，不看文件扩展名：PDF 也可以是笔记；
- Markdown 文件会先放进 `inbox/`，需要到「操作与日志」点「导入 inbox」。

### 笔记编辑

点笔记标题或「编辑」：

- 标题、文件夹、分类、日期、标签、摘要、Markdown 正文；
- 「预览」可以看排版和公式；
- 保存后回到列表，需要点「发布上线」才会上线。

### 文件条目

- 点「打开」在本地预览页查看；
- 删除会同时删掉资料条目和 `public/files/` 里的文件；
- 文件条目的标题、描述暂不支持在网页里改。

## 站点

- **站点信息**：站名、英文名、浏览器标题、作者、邮箱、年份、首页两行大标题、站点简介、页脚；
- **首页自我介绍**：显示在首页大标题右侧的整段文字；
- **关于页**：标题、摘要、Markdown 正文，以及任意条「名称 + 链接」；
  - 链接可以是 `https://` 社媒主页、个人主页，或 `mailto:` 邮箱；
  - 可以增删多条，保存后需发布。

## 操作与日志

- **导入 inbox**：运行 `npm run import`；
- **只构建检查**：运行 `npm run build`，不发布；
- **构建并发布**：构建 → `git add` → `git commit` → `git push`；
- 日志实时滚动，失败时看最后几行。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 本地站点打不开 | 顶部状态显示「本地预览运行中」才可点；未启动时点一下会自动拉起 |
| 4322 打不开 | 确认 `npm run admin` 还在运行；端口冲突时 `$env:ADMIN_PORT=4400; npm run admin` |
| 上传超过 50MB | 设计如此，先压小或用网盘 |
| 发布失败 | 看日志；构建失败先修内容，git 失败检查 Clash |
| 改了没生效 | 需要点「发布上线」，保存本身不上线 |

## 边界

写作台只管理**内容**（笔记、资料、首页介绍、关于页、站点文字）。布局、配色、动画仍然通过对话让 AI 改，避免在网页里编辑代码。
