# 写作台（本地管理后台）

不想面对文件夹和终端时，用这个本地网页改内容。

## 启动

在 `C:\blog` 打开 PowerShell：

```powershell
npm run admin
```

会自动打开 **http://127.0.0.1:4322**，同时自动启动本地预览 **http://localhost:4321**。

关闭：在终端按 `Ctrl + C`，两个服务会一起停。

> 写作台只监听本机，不要暴露到公网。

## 资料库

笔记和文件现在放在同一个「资料库」里，按文件夹归类：

```text
微积分Ⅰ / 线性代数 / 保研资料 / 学习方法 / 其他
```

- 左边是文件夹树，支持多级子文件夹；
- 点文件夹筛选；「全部」显示所有条目；
- 选中某个文件夹后，点「+ 新建文件夹」会在它下面建子文件夹；
- 条目可以直接拖到左侧文件夹里，只改归类，**不改变已有 URL**；
- 文件夹里还有内容或子文件夹时不能删除；
- 「新建笔记」会在当前文件夹里建一篇 Markdown 笔记；
- 「上传文件」前先选「上传为 资料 / 笔记」，再拖入或选择 PDF / Word / PPT / ZIP；
- 类型由你上传时的选择决定，不看文件扩展名：PDF 也可以是笔记；
- Markdown 文件会先放进 `inbox/`，需要到「操作与日志」点「导入 inbox」。

### 笔记编辑

点笔记标题或「编辑」：

- 标题、文件夹、分类、日期、标签、摘要、Markdown 正文；
- 「预览」可以看排版和公式；
- 保存后回到列表，需要点「发布上线」才会上线。

### 带图片的 Markdown 笔记

单独上传 `.md` 时，图片不会跟着走，页面上会显示缺图。带图片的笔记请打成一个 zip：

```text
我的笔记.zip
├─ 我的笔记.md
├─ images/
│  ├─ 图1.png
│  └─ 图2.png
└─ 图3.png
```

- `.md` 里的 `![](images/图1.png)` 会保持相对路径；
- Obsidian 的 `![[图3.png]]` 会自动转成普通图片并复制进去；
- 上传时把「上传为」选成 **笔记包 (.zip)**，再选择当前文件夹；
- 服务器会解压、复制图片到 `src/content/posts/<笔记名>/`，并生成笔记。

已经缺图的笔记，重新打包成 zip 上传会生成一篇新笔记；确认图片正常后，把旧的那篇删掉即可。

### Word / PPT 在线预览

上传 `.docx`、`.doc`、`.pptx`、`.ppt` 时，写作台会自动用 LibreOffice 生成同名 PDF：

- 资料页用 PDF 阅读器在线预览；
- 原 Word/PPT 文件仍保留，可点「下载原文件」；
- 转换失败时仍保留原文件，只是没有在线预览。

已有的 Word/PPT 资料也已批量生成 PDF 预览。
### 从文件夹导入带图笔记

如果笔记和图片散在一个本地文件夹里，不用手动打包：

1. 选中目标文件夹（例如 `C语言/逊哥`）；
2. 点「从文件夹导入」；
3. 填入本地文件夹路径，例如：
   `C:\Users\29459\Documents\资料\02-课程-2026秋\C语言课程资料`
4. 点「1. 扫描并检查图片」：
   - 会扫描该文件夹（含子文件夹）里所有 `.md`；
   - 解析 `![](...)` 和 Obsidian 的 `![[...]]`；
   - 按「同目录相对路径 → 文件夹内同名文件」查找图片；
   - 列出每篇笔记的图片数量、缺失图片、同名冲突。
5. 确认无误后点「2. 导入这些笔记」，图片会复制到 `src/assets/imported/`（按内容哈希命名、自动去重），链接自动改写。

注意：

- 路径必须是本机真实存在的文件夹；
- 图片找不到时会标红，可以先补图再扫描；
- 勾选「覆盖同名笔记」会直接覆盖，不勾选会生成新副本。

### 文件条目

- 点「打开」在本地预览页查看；
- 删除会同时删掉资料条目和 `public/files/` 里的文件；
- 文件条目的标题、描述暂不支持在网页里改。

## 站点

- **站点信息**：站名、英文名、浏览器标题、作者、邮箱、年份、首页两行大标题、站点简介、页脚；
- **首页自我介绍**：显示在首页大标题右侧的整段文字；
- **关于页**：标题、摘要、Markdown 正文，以及任意条「名称 + 地址」；
  - 类型选「跳转链接」：点击后打开网页，例如 GitHub；
  - 类型选「显示文本（可复制）」：只显示邮箱/账号文字和「复制」按钮，不跳转；
  - 链接可以是 `https://` 社媒主页、个人主页，或 `mailto:` 邮箱；
  - 可以增删多条，保存后需发布。

## 操作与日志

- **导入 inbox**：运行 `npm run import`；
- **只构建检查**：运行 `npm run build`，不发布；
- **构建并发布**：构建 → `git add` → `git commit` → `git push`；
- 日志实时滚动，失败时看最后几行。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 本地站点打不开 | 顶部状态显示「本地预览运行中」才可点；未启动时点一下会自动拉起 |
| 4322 打不开 | 确认 `npm run admin` 还在运行；端口冲突时 `$env:ADMIN_PORT=4400; npm run admin` |
| 上传超过 50MB | 设计如此，先压小或用网盘 |
| 发布失败 | 看日志；构建失败先修内容，git 失败检查 Clash |
| 改了没生效 | 需要点「发布上线」，保存本身不上线 |

## 边界

写作台只管理**内容**（笔记、资料、首页介绍、关于页、站点文字）。布局、配色、动画仍然通过对话让 AI 改，避免在网页里编辑代码。
